# Trailhead Maps, offline trail planner

## Facts
- An open-source mobile app that plans hikes with no signal: React Native and TypeScript, with OpenStreetMap data stored in SQLite on the phone.
- 9,000 installs and 12 outside contributors as of 2026-01.
- Jordan wrote the tile packer that shrinks a regional map from 900 MB to 110 MB.
- GitHub Actions builds and tests every pull request. Jordan has reviewed 85 pull requests from the 12 outside contributors.

## Bullets
- [open-source] Shrank a regional offline map from 900 MB to 110 MB with a tile packer for a React Native app with 9,000 installs.
